# FREKANS Product Contract

## Core promise

**Müzik burada konuşulur.**

FREKANS is a social space for people who want to discover, share, discuss, and connect around music.

## What FREKANS is not

- A generic Instagram-style social feed
- A music streaming replacement
- A dating app whose primary mechanic is compatibility scoring
- A product that requires Spotify listening-history analysis

## Core objects

- User
- Profile
- Artist
- Album
- Song
- Post
- Topic
- Comment
- Follow
- Conversation
- Message
- Report

## MVP user journey

```text
Sign up
  ↓
Create profile
  ↓
Choose artists/songs
  ↓
Enter community
  ↓
Read / create a topic
  ↓
Comment / like
  ↓
Open a profile
  ↓
Follow or message
  ↓
Share a song
  ↓
Open it in Spotify
```

## Community rule

Every major feature must answer at least one of these questions:

- Does it help people discover music?
- Does it help people talk about music?
- Does it help people share music-related thoughts?
- Does it help people find other music-interested people?

If it does none of these, it does not belong in the MVP.

## Moderation principle

FREKANS protects the music-focused community without trying to remove every unpopular opinion. Music criticism is allowed; harassment, spam, threats, targeted abuse, and unrelated commercial content are not.
